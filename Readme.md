# Android Clean Planet Game

## 🚀 Author
Bojan Brankovic 

## Project Overview
This project is an Android Clean Planet Game focused on environmental awareness and interactive gameplay. The objective of the game is to clean polluted environments, collect waste, and restore balance to the planet through engaging mechanics.

Games with similar concepts often combine casual gameplay with ecological themes, where players clean environments or manage recycling systems to improve the virtual world. :contentReference[oaicite:0]{index=0}  

The goal of this project is to demonstrate game logic implementation, user interaction, and mobile performance within a simple but meaningful game scenario.

## Features
- Interactive gameplay focused on cleaning the environment  
- Object collection (waste, items, or resources)  
- Progress-based game flow  
- Score or progress tracking  
- Simple and intuitive controls  
- Basic animations and visual feedback  

## Tech Stack
- Java / Kotlin (Android)
- Android SDK
- Android Studio

## Game Objective
- Navigate through the environment  
- Collect or remove polluted elements  
- Progress through levels or stages  
- Improve the overall “cleanliness” of the planet  

## Application Flow
1. User launches the game  
2. Game environment is loaded  
3. Player interacts with objects (cleaning/collecting)  
4. Progress is tracked  
5. Game continues until objective is completed
